# レポートの条件付きセクション表示

## 作業日時
2026-04-11

## 概要
設計レポートのプロンプトテンプレートで、Entity変更がない場合や把握できなかった意図がない場合に、不要なセクションが出力されないよう条件分岐を追加。

## 変更内容

### `src/design-decisions/prompts.ts`
- `hasEntityChanges` フラグを追加し、`data.entityChanges` の有無でプロンプト内容を分岐
- Entity変更がない場合:
  - 「データ構造の変化」セクション（テンプレート例・詳細記載方法）を除外
  - 主要セクション数を「3」→「2」に変更
  - 「データ構造の変化セクションは出力しないでください」という明示的な指示を追加
- 「把握できなかった意図」セクション:
  - 該当がない場合はセクション自体を出力しないよう指示を追加
