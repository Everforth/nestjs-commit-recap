# maxTokens制限の改善

## 作業日時
2026-04-04 17:05

## 概要
Design Decisions機能のAI出力トークン制限を改善しました。デフォルト値を8,192から64,000に増加し、出力が切り詰められた際の検出・警告機能、およびユーザーがカスタム値を設定できる`--max-tokens`オプションを追加しました。

## 背景
- 従来のmaxTokens: 8,192では、詳細な設計レポートが途中で切れる問題が発生
- 切り詰めが発生してもユーザーに通知されない
- ユーザーがトークン数を調整する手段がない

## 変更内容

### 1. `src/ai/anthropic-client.ts`
**追加機能:**
- `chalk`のインポートを追加
- `sendMessage`メソッドに切り詰め検出ロジックを実装
  - APIレスポンスの`stop_reason`が`"max_tokens"`の場合に警告を表示
  - 日本語の警告メッセージで`--max-tokens`オプションの使用を案内

**実装詳細:**
```typescript
// 切り詰め検出
if (message.stop_reason === "max_tokens") {
  console.warn(
    chalk.yellow(
      `\n⚠️  警告: AIレスポンスが最大トークン数 (${this.maxTokens}) に達したため、出力が途中で切り詰められた可能性があります。`
    )
  );
  console.warn(
    chalk.yellow(
      `    より長い出力が必要な場合は --max-tokens オプションで値を増やしてください。`
    )
  );
}
```

### 2. `src/design-decisions/index.ts`
**追加機能:**
- `--max-tokens <number>`オプションを追加（デフォルト: 64000）
- オプション型定義に`maxTokens: string`を追加
- AnthropicClientの初期化時にユーザー指定のmaxTokensを使用

**変更箇所:**
- line 27: `.option("--max-tokens <number>", "AI出力の最大トークン数", "64000")`を追加
- line 37: 型定義に`maxTokens: string;`を追加
- line 98: `maxTokens: Number.parseInt(options.maxTokens, 10)`に変更

## 使い方

### デフォルト値（64,000トークン）で実行
```bash
npm run design-catchup -- . --days 7
```

### カスタム値を指定
```bash
npm run design-catchup -- . --days 7 --max-tokens 100000
```

### 切り詰め警告の確認（テスト用）
意図的に低い値を設定すると警告が表示されます:
```bash
npm run design-catchup -- . --days 7 --max-tokens 100
```

出力例:
```
✔ データ収集完了
⠹ AI分析を実行中...
⚠️  警告: AIレスポンスが最大トークン数 (100) に達したため、出力が途中で切り詰められた可能性があります。
    より長い出力が必要な場合は --max-tokens オプションで値を増やしてください。
✔ レポート生成完了
```

## デフォルト値の根拠
- Claude Sonnet 4.5の最大出力トークン数: 64,000
- 従来の8,192は詳細な設計レポート生成には不十分
- ユーザーが必要に応じて`--max-tokens`オプションで調整可能
